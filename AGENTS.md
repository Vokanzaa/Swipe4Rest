# Swipe4Rest project rules

- Independent application/repository `Vokanzaa/Swipe4Rest`, developed from the extended DragShift base. Preserve original MIT and third-party attribution.
- All future conversion/format-processing features and shared fixes must also reach the user's `Vokanzaa/DragShift` source and release packages. Updating this repository alone does not update DragShift.
- Keep product-specific UI separate: Swipe4Rest uses a branching workflow menu; DragShift keeps its radial UI. The user will decide the main product after manual testing.
- Verify Windows, Linux, Mac Apple Silicon and Intel build paths for each applicable change. Publish only tested complete releases; distinguish source publication from downloadable binaries.
- All processing is local. Do not put credentials, logs, working user files, personal reference images or project-memory conversations into the public repository.
- Public change documentation must not name the user's proprietary print reference application. No inherited donation solicitation; the user has not supplied a donation URL.
- Work in the current Swipe4Rest checkout; never overwrite a separately installed DragShift or its production checkout as an incidental part of a Swipe4Rest build.
